# NOME DO SISTEMA

HelpDesk - Sistema de Chamados

# DESCRIÇÃO

O HelpDesk é um sistema desktop, desenvolvido em Java com programação orientada a objetos, destinado ao gerenciamento de chamados técnicos dentro de uma empresa. O sistema permite registrar problemas, identificar o solicitante, definir o nível de urgência, atribuir um responsável pelo atendimento e registrar as datas de abertura e fechamento de cada chamado. Seu objetivo é organizar e agilizar o atendimento das solicitações de suporte.

# FUNCIONALIDADES

- Abrir chamado.
- Identificação do solicitante.
- Adicionar descrição do problema.
- Definir categoria do chamado (Hardware, Software, Rede, entre outras).
- Definir nível de urgência (Baixo, Médio ou Alto).
- Atribuir o responsável pelo atendimento.
- Registrar automáticamente a data de abertura e fechamento do chamado.
- Comentário do técnico ao chamado.
- Alterar informações do chamado.
- Alterar status do chamado (Aberto, Em andamento ou Concluído)
- Consultar os chamados cadastrados.
